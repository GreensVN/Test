--------------------------------------------------------------------------------
I. TÓM TẮT 10 GIÂY
--------------------------------------------------------------------------------
Bỏ `pyaudio` ra khỏi lệnh, thay bằng `sounddevice`, và cài TỪNG GÓI MỘT:

    python -m pip install --upgrade pip setuptools wheel
    python -m pip install pyttsx3
    python -m pip install SpeechRecognition
    python -m pip install sounddevice numpy
    python -m pip install rapidfuzz
    python -m pip install pytest

Hoặc bấm đúp file:  cai_dat_giong_noi.bat  (đã làm sẵn tất cả việc trên)

--------------------------------------------------------------------------------
II. TẠI SAO CẢ 5 GÓI ĐỀU KHÔNG CÀI ĐƯỢC?
--------------------------------------------------------------------------------
Thực ra chỉ có MỘT gói hỏng, nhưng nó kéo sập cả dòng lệnh.

pip xử lý cả dòng như MỘT GIAO DỊCH: nó giải quyết phụ thuộc cho TẤT CẢ gói
trước, rồi mới cài. Chỉ cần 1 gói thất bại → pip HỦY TOÀN BỘ, không gói nào
được cài. Đó là lý do bạn tưởng "không tải được gì cả".

Tình trạng từng gói:

  Gói                | Kiểu        | Trên Win 10 + Python 3.13
  -------------------|-------------|---------------------------------------------
  pyttsx3            | thuần Python| OK
  SpeechRecognition  | thuần Python| OK
  pytest             | thuần Python| OK
  rapidfuzz          | C ext       | OK (có wheel cp313)
  pyaudio            | C ext       | HỎNG  <-- THỦ PHẠM

Hai nguyên nhân cụ thể:

  1) pyaudio KHÔNG có wheel cho Python 3.13.
     PyAudio bản mới nhất (0.2.14) chỉ có wheel tới cp312. Với Python 3.13,
     pip phải biên dịch từ mã nguồn C → báo một trong hai lỗi:

         error: Microsoft Visual C++ 14.0 or greater is required.
         Get it with "Microsoft C++ Build Tools"

         fatal error C1083: Cannot open include file: 'portaudio.h':
         No such file or directory

     (Giống hệt bản chất lỗi Cython của scikit-learn ở FIX_LOI_CYTHON_WIN10.txt:
      thiếu wheel → pip tự build → thiếu trình biên dịch → vỡ.)

  2) GÕ SAI TÊN GÓI.
     Trong lần gõ thứ hai bạn viết "rapidfuz" (thiếu chữ z cuối).
     pip sẽ báo và hủy toàn bộ dòng lệnh:

         ERROR: Could not find a version that satisfies the requirement rapidfuz
         ERROR: No matching distribution found for rapidfuz

     Tên ĐÚNG là:  rapidfuzz   (hai chữ z)

--------------------------------------------------------------------------------
III. TIN TỐT: DỰ ÁN NÀY KHÔNG CẦN pyaudio
--------------------------------------------------------------------------------
Mở stt.py, hàm STT._record() (khoảng dòng 120-155): nó thu âm bằng

        import sounddevice as sd
        with sd.InputStream(samplerate=16000, channels=1, dtype="int16") as stream:

Rồi đóng gói thành WAV trong bộ nhớ và đẩy qua sr.AudioFile() để nhận diện.
Tức là SpeechRecognition chỉ làm nhiệm vụ GIẢI MÃ, còn MICRO do sounddevice lo.

Chính docstring đầu file stt.py cũng ghi 2 phương án:
        pip install transformers torch sounddevice
        pip install SpeechRecognition sounddevice

sounddevice đóng gói sẵn thư viện PortAudio bên trong wheel → KHÔNG cần trình
biên dịch C++, cài mọi phiên bản Python đều được.

LƯU Ý DUY NHẤT: cờ `--voice` (chế độ đơn giản) trong main.py có dùng
sr.Microphone() - hàm này vẫn cần pyaudio. Nếu không có pyaudio, hãy dùng
lệnh `mic` đầy đủ trong chương trình (đi qua lớp STT + sounddevice) thay vì cờ
--voice. Chức năng như nhau.

--------------------------------------------------------------------------------
IV. LIỆT KÊ ĐẦY ĐỦ CÁC CÁCH SỬA (chọn 1 cách)
--------------------------------------------------------------------------------

=== CÁCH 1 - Bỏ pyaudio, dùng sounddevice (KHUYẾN NGHỊ) ===

    python -m pip install pyttsx3 SpeechRecognition sounddevice numpy rapidfuzz pytest

  Không cần trình biên dịch, chạy được trên mọi phiên bản Python.


=== CÁCH 2 - Cài từng gói một (để biết chính xác gói nào hỏng) ===

    python -m pip install pyttsx3
    python -m pip install SpeechRecognition
    python -m pip install pytest
    python -m pip install rapidfuzz
    python -m pip install sounddevice numpy

  Hoặc bấm đúp:  cai_dat_giong_noi.bat


=== CÁCH 3 - Vẫn muốn pyaudio: hạ xuống Python 3.12 ===

    py -3.12 -m venv .venv
    .venv\Scripts\activate
    pip install --upgrade pip
    pip install pyttsx3 SpeechRecognition pyaudio pytest rapidfuzz

  Python 3.12 có wheel PyAudio 0.2.14 sẵn → cài mượt.


=== CÁCH 4 - Vẫn muốn pyaudio trên Python 3.13: tải wheel thủ công ===

    1. Vào  https://pypi.org/project/PyAudio/#files
       hoặc  https://github.com/intxcc/pyaudio_portaudio/releases
    2. Tải file khớp:  PyAudio-0.2.14-cp313-cp313-win_amd64.whl
       (cp313 = Python 3.13, cp312 = 3.12; win_amd64 = Windows 64-bit)
    3. pip install đường\dẫn\PyAudio-0.2.14-cp313-cp313-win_amd64.whl


=== CÁCH 5 - pipwin (cách cũ, hay được chỉ trên mạng) ===

    pip install pipwin
    pipwin install pyaudio

  LƯU Ý: pipwin đã ngừng bảo trì, thường hỏng trên Python 3.12+.
  Chỉ thử nếu Cách 3/4 không dùng được.


=== CÁCH 6 - Cài trình biên dịch để build pyaudio thật ===

    1. Tải "Build Tools for Visual Studio 2022":
       https://visualstudio.microsoft.com/visual-cpp-build-tools/
    2. Khi cài, tick workload "Desktop development with C++"
    3. Khởi động lại máy, rồi:  pip install pyaudio

  Tốn ~6 GB và 15-40 phút. KHÔNG khuyến nghị khi đã có sounddevice.


=== CÁCH 7 - Không cài gì, vẫn có giọng nói ===

  tts.py có 4 tầng dự phòng: kho giọng cache → pyttsx3 → Windows SAPI → gTTS.
  Trên Windows, tầng SAPI chạy qua PowerShell có sẵn của hệ điều hành, KHÔNG
  cần cài gì. Cứ chạy:

        python main.py --speak

--------------------------------------------------------------------------------
VI. QUY TẮC CHUNG ĐỂ KHÔNG DÍNH LẠI
--------------------------------------------------------------------------------
1. Luôn nâng pip trước:
       python -m pip install --upgrade pip setuptools wheel

2. Cài từng gói một khi đang thử nghiệm, đừng gộp 5 gói vào 1 dòng.

3. Thêm cờ này để pip BÁO LỖI NGAY thay vì ngồi biên dịch hàng nghìn dòng:
       pip install --only-binary=:all: <tên_gói>

4. Kiểm tra tên gói trước khi gõ:  https://pypi.org/project/<tên_gói>/
   Dễ gõ nhầm: rapidfuzz (2 chữ z), SpeechRecognition (viết hoa S và R),
   pyttsx3 (có số 3), gTTS.

5. Toàn bộ các gói này đều LÀ TUỲ CHỌN. Không cài được cũng không sao:
       python main.py
   vẫn chạy bình thường.
