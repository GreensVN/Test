================================================================================
  SỬA LỖI "Error compiling Cython file" KHI pip install TRÊN WINDOWS 10 / 11
  (bản v6.3 - cập nhật cho Python 3.9 → 3.13)
================================================================================

--------------------------------------------------------------------------------
I. TRIỆU CHỨNG
--------------------------------------------------------------------------------
Chạy `pip install -r requirements.txt` trên Windows 10 thì đổ ra hàng nghìn dòng:

    Error compiling Cython file:
    sklearn\tree\_criterion.pyx:1252:32: Converting to Python object not allowed without gil
    sklearn\tree\_tree.pxd:16:9: 'npy_float32' is not a type identifier
    sklearn\tree\_utils.pxd:39:4: Type specified multiple times
    ...
    numpy\__init__.pxd:12:13: Error in compile-time expression:
      ValueError: invalid literal for int() with base 10:
      'Build aborted: the NumPy Cython headers require Cython 3.0.0 or newer.'
    Cython.Compiler.Errors.CompileError: sklearn\tree\_criterion.pyx

--------------------------------------------------------------------------------
II. NGUYÊN NHÂN (không phải lỗi code của dự án)
--------------------------------------------------------------------------------
1. File requirements.txt bản cũ ghim cứng:  scikit-learn>=1.3.0,<1.4.0
   (ghim như vậy để còn chạy được trên Windows 7 / Python 3.8).

2. Trên Windows 10 bạn đang dùng Python 3.13 (hoặc 3.14). PyPI KHÔNG có bản
   dựng sẵn (wheel .whl) của scikit-learn 1.3.x cho Python 3.13.

3. Không có wheel, pip chuyển sang TỰ BIÊN DỊCH TỪ MÃ NGUỒN bằng Cython 3 +
   NumPy 2. Nhưng scikit-learn 1.3.x được viết cho Cython 0.29 + NumPy 1,
   nên sai cú pháp hàng loạt (SIZE_t, npy_intp, nogil, const...) → vỡ trận.

BẢNG TƯƠNG THÍCH

  Python trên máy | scikit-learn 1.3.x có wheel? | pip sẽ làm gì        | Nên cài
  ----------------|------------------------------|----------------------|------------
  3.8 (Win 7)     | Có (cp38)                    | Tải wheel → OK       | 1.3.2
  3.9 - 3.11      | Có                           | Tải wheel → OK       | mới nhất
  3.12            | Có (từ 1.3.2)                | Tải wheel → OK       | mới nhất
  3.13            | KHÔNG                        | Biên dịch → LỖI      | >= 1.5.1
  3.14            | KHÔNG                        | Biên dịch → LỖI      | mới nhất

Kiểm tra Python của bạn:      python --version

--------------------------------------------------------------------------------
III. LIỆT KÊ ĐẦY ĐỦ CÁC CÁCH SỬA (chọn 1 cách là đủ)
--------------------------------------------------------------------------------

=== CÁCH 1 - KHÔNG CÀI GÌ CẢ (nhanh nhất, 0 giây) ===

  Dự án v6.3 KHÔNG bắt buộc scikit-learn. Thiếu nó thì chương trình tự dùng
  lite_model.py (Naive Bayes thuần Python, chính xác ~97-98%).

      cd đường\dẫn\tới\vi_voice_assistant
      python main.py

  Hoặc bấm đúp file:  CHAY_NGAY.bat
  Ưu   : không cần mạng, không cần cài đặt, không bao giờ dính lỗi này.
  Nhược: kém TF-IDF một chút ở câu dài / viết sai chính tả nặng.


=== CÁCH 2 - CÀI BẢN scikit-learn MỚI (KHUYẾN NGHỊ) ===

      python -m pip install --upgrade pip setuptools wheel
      python -m pip install --only-binary=:all: --upgrade scikit-learn joblib

  Cờ  --only-binary=:all:  RẤT QUAN TRỌNG: nó cấm pip biên dịch từ mã nguồn.
  Nếu không có wheel, pip báo lỗi ngắn gọn ngay thay vì đổ nghìn dòng Cython.

  Hoặc bấm đúp file:  cai_dat_win10.bat  (tự tạo venv + cài + kiểm tra)

  Code trong intent_model.py / train_nlu.py chỉ dùng TfidfVectorizer,
  LogisticRegression, LinearSVC, CalibratedClassifierCV, Pipeline, FeatureUnion,
  GridSearchCV, StratifiedKFold - tất cả vẫn chạy bình thường trên 1.5 - 1.7.


=== CÁCH 3 - DÙNG requirements.txt ĐÃ SỬA (đã kèm trong gói này) ===

      python -m pip install --upgrade pip setuptools wheel
      python -m pip install -r requirements.txt

  File requirements.txt trong gói này đã dùng "environment marker":

      scikit-learn>=1.3.0,<1.4.0 ; python_version <  "3.9"   <- Win 7 / Py 3.8
      scikit-learn>=1.5.0        ; python_version >= "3.9"   <- Win 10 / 11

  Nên cùng 1 file chạy đúng trên CẢ Windows 7 lẫn Windows 10/11.


=== CÁCH 4 - GIỮ ĐÚNG BẢN 1.3.2 BẰNG PYTHON 3.12 ===

  Nếu bắt buộc phải dùng scikit-learn 1.3.x (ví dụ để đồng bộ với máy khác):

    1. Cài Python 3.12 tại https://www.python.org/downloads/release/python-3128/
       (nhớ tích "Add python.exe to PATH")
    2. Chạy:
         py -3.12 -m venv .venv
         .venv\Scripts\activate
         pip install --upgrade pip
         pip install scikit-learn==1.3.2 joblib==1.4.2
         python main.py


=== CÁCH 5 - TẢI THỬ CÔNG FILE .whl (khi mạng công ty chặn PyPI) ===

    1. Vào https://pypi.org/project/scikit-learn/#files
    2. Tải file khớp Python + Windows 64-bit của bạn, ví dụ Python 3.13:
         scikit_learn-1.7.x-cp313-cp313-win_amd64.whl
       (cp313 = Python 3.13, cp312 = 3.12, cp311 = 3.11 ...)
    3. Cài bằng:
         pip install đường\dẫn\tới\scikit_learn-1.7.x-cp313-cp313-win_amd64.whl


=== CÁCH 6 - CÀI TRÌNH BIÊN DỊCH ĐỂ BUILD THẬT (KHÔNG KHUYẾN NGHỊ) ===

  Chỉ làm khi bạn thật sự cần build scikit-learn từ mã nguồn. Phải có:
    - Visual Studio Build Tools 2022 + workload "Desktop development with C++"
    - Cài trước: pip install "cython<3" "numpy<2" scipy
    - Rồi:      pip install --no-build-isolation scikit-learn==1.3.2
  Mất 15-40 phút, tốn ~6 GB ổ đĩa, và vẫn rất dễ lỗi. Nên dùng CÁCH 2.

IV. KIỂM TRA ĐÃ THÀNH CÔNG CHƯA
--------------------------------------------------------------------------------
      python main.py --version

  Nếu thấy:
      [MODEL] Đang dùng model nhẹ thuần Python (không cần scikit-learn).

  Xem chi tiết tất cả tính năng đang bật/tắt:
      python -c "import platform_utils; platform_utils.print_feature_report()"

--------------------------------------------------------------------------------
V. CÁC LỖI pip HAY GẶP KHÁC TRÊN WINDOWS 10
--------------------------------------------------------------------------------
1. "Microsoft Visual C++ 14.0 or greater is required" khi cài pyaudio
     → pip install pipwin
       pipwin install pyaudio
     Hoặc bỏ qua: STT chỉ là tính năng tuỳ chọn.

2. "DLL load failed while importing _multiarray_umath"
     → Cài "Microsoft Visual C++ Redistributable 2015-2022 (x64)".

3. "rapidfuzz không nạp được" (cảnh báo khi khởi động)
     → VÔ HẠI. Chương trình tự chuyển sang difflib có sẵn của Python.
       Muốn hết cảnh báo:  pip install rapidfuzz

4. Tiếng Việt hiển thị thành ô vuông / dấu ?
     → Chạy trong Windows Terminal, hoặc gõ:  chcp 65001  trước khi chạy.
       Hai file .bat kèm theo đã tự làm điều này.

5. pip báo "externally-managed-environment"
     → Dùng môi trường ảo:  python -m venv .venv && .venv\Scripts\activate
